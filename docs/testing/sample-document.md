# Politique de congés — Acme Corp

## Congés payés

Chaque employé à temps plein bénéficie de 25 jours de congés payés par an.
Les congés doivent être demandés au moins 2 semaines à l'avance via le
formulaire RH.

## Télétravail

Les employés peuvent télétravailler jusqu'à 3 jours par semaine. Les
alternants doivent être présents sur site tous les jours pendant leur
premier mois.

## Jours fériés

L'entreprise observe les 11 jours fériés légaux français. Aucun jour de
congé payé n'est décompté pour ces journées.
